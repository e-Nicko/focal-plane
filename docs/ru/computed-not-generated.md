# Каждый кадр вычислен

Каждый кадр фильма — функция времени.
Ничто не получено сэмплированием из модели, не записано с экрана и не выставлено ключами вручную.

## Кадр — это `f(t)`

- `state(t)` плана — чистая функция: при том же `t` получаются те же курсор, фокус и значения.
- Ключи камеры интерполируются сплайном и никогда не симулируются.
- Данные создаются один раз генераторами с фиксированным зерном (seed).
- Плёночное зерно зависит от номера кадра; часы не читаются никогда.

Поэтому кадры можно рендерить в любом порядке, параллельно или по одному.
Плеер в браузере и офлайн-рендерер выполняют один и тот же код
и различаются только тем, какие моменты времени запрашивают.

## Что это даёт

| | Сгенерированное видео | Вычисленный фильм |
|---|---|---|
| первый кадр | через секунды после промпта | через часы написания кода |
| текст | читается там, где модели это удалось | чёткий в 4K, везде |
| числа | какие выглядели правдоподобно | согласованы друг с другом ([честные данные](honest-data.md)) |
| правка | новый промпт и новый бросок костей | изменить значение и отрендерить заново |
| тот же кадр дважды | не гарантирован | тот же, с точностью до одного уровня в нескольких пикселях |
| ревью | посмотреть | посмотреть, сравнить попиксельно, прочитать код |

## Генераторы выучили этот жанр

Видеомодели знают этот жанр.
В руководстве по промптам Seedance 2.0 для него есть шаблон:
превью SaaS-приложения, в котором курсор проводит интерфейс
от пустого состояния до состояния успеха.
Референсный ролик, который мы изучали, скорее всего, сгенерирован:
в его размытых зонах текст расползается в кашу.

Генератор хорош, чтобы найти настроение.
Для показа продукта он плох,
потому что весь смысл — в текстах и числах продукта.

## Почему подходит агент

Грамматика на этих страницах достаточно явная, чтобы её записать,
а значит, её можно записать и кодом.
Агент, который пишет план, может отрендерить кадр, посмотреть на него и поправить камеру —
тот же цикл, что проходит моушен-дизайнер в After Effects.
[Скилл](../../skills/focal-plane/SKILL.md) даёт агенту этот цикл.
