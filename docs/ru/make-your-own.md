# Сделайте свой фильм

Новая история за шесть шагов.
Агент может пройти тот же цикл с помощью [скилла](../../skills/focal-plane/SKILL.md).

## 1. Напишите список планов

По одному предложению на план, и в каждом — причина и следствие:

```
1. вводный план: страница и её главное число
2. курсор включает округление покупок, и прогноз баланса прокручивается вверх
3. ...
```

От пяти до восьми планов дают фильм длиной от двенадцати до двадцати секунд.

## 2. Соберите все числа в одном модуле

Создайте `src/<film>/data.ts`.
Любую случайность стройте на генераторе с фиксированным зерном;
никогда не вызывайте `Math.random()` и не читайте часы.
Каждое число, которое показывает план, получайте из этого модуля
([честные данные](honest-data.md)).

## 3. Напишите планы

Для каждого плана скопируйте `skills/focal-plane/templates/shot.ts`
в `src/<film>/shots/<id>.ts`, а затем:

- задайте размер страницы и нарисуйте её в `draw()`;
- двигайте курсор, элементы управления и значения в `state(t)`
  и возвращайте `focus: [x, y]`;
- задайте два ключа камеры;
- задайте плану тип состояния,
  чтобы `bun run typecheck` сверил то, что возвращает `state()`, с тем, что читает `draw()`.

## 4. Соберите монтаж

Скопируйте `templates/edit.ts` в `src/<film>/edit.ts` и перечислите в нём планы.
Скопируйте `templates/main.ts` в `src/<film>/main.ts`.
Теперь плеер воспроизводит фильм по адресу `index.html?film=<film>`.
Перед первым кадром запустите `bun run typecheck`.

## 5. Выстройте композицию по стоп-кадрам

```bash
bun run shoot --film=<film> --shot=<id> --lt=0.3,0.8,1.6,2.2 --sheet
```

Посмотрите на каждый кадр.
Сдвиньте `look` ниже по странице, чтобы содержимое поднялось в кадре,
меняйте `azimuth` и `elevation`, чтобы подобрать ракурс,
и снимайте снова.
Перед рендером проверьте весь монтаж на одном контактном листе.

## 6. Отрендерите и проверьте

```bash
bun run render --film=<film>
bun run verify out/<film>-2160p60.mp4 --at=1,5,9
```

Прежде чем считать работу законченной, посмотрите на декодированные кадры.
Затем сделайте обложку: скопируйте `tools/media.ts` и задайте в нём `CUT` и `STILLS` под свои планы.

Назад к [документации](README.md).
