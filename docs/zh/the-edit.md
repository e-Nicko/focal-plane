# 剪辑

七个镜头，硬切，16 秒。
镜头之间没有叠化，没有划像，也没有相机飞行过渡。

## 硬切

只要切换的那一刻有东西开始运动，
切换就是瞬间的，观众几乎不必为此付出代价。

- **在运动开始时切换**。
  每个有光标的镜头，光标在最初几帧就开始移动，
  所以每一次切换都与一次运动的开始重合，
  而这样的切换更常被忽略（Smith 和 Henderson，2008，见[为什么有效](why-it-works.md)）。
- **让点击成为切换的理由**。
  tabs 镜头在点击 Forecast 的涟漪消散时结束，
  下一个镜头以 Forecast 视图开场。

影片开头用 0.35 秒淡入，结尾用 0.7 秒淡出。
除此之外没有别的淡入淡出。

## 故事

展示一个问题和它的答案，
与之无关的控件一律略去：

1. **定场**：页面和它的核心数字（overview）。
2. **行动**：选一个视图，打开它，再往前推一步（tabs、forecast、horizon）。
3. **解读**：行动产生了什么（months）。
4. **发现**：不合群的东西（anomaly）。
5. **拉远**：回到同一个页面，此时它已经变了（outro）。

outro 就是开场镜头的重现，只是其中带着故事的结果：
预测已打开，预测期为 90 天，离群值被圈了出来。
观众认出这个页面，也看到了哪些东西变了。

## 节奏

镜头时长在 1.8 到 2.6 秒之间。
陡峭的镜头和平静的镜头交替出现（[镜头](the-shot.md)），
唯一一次换边是换到右侧，伴随着一个新主题：月份。
最长的镜头 anomaly 承载着发现。

## 连贯性

每个镜头都读取同一个数据模块，
所以在一个镜头里看到的数字，到下一个镜头还是同一个数字（[诚实的数据](honest-data.md)）。
页面、字体和调色在镜头之间从不改变。
变的只有相机。

## 封面帧

偏好减少动态效果的观众会看到一帧静帧：
第 5.8 秒，预测曲线已经画出，数值也已标注。
要选单独拿出来也能讲出最多故事的那一帧。
