# 画面

暗色页面，灰色文字，没有色彩，没有辉光。
调色让画面有胶片的质感。

## 先测量，再匹配

目标值来自对参考样片的逐帧测量（[我们如何知道](how-we-know.md)）：

| 指标 | 参考样片 | 本项目 |
|---|---|---|
| 最暗的黑 | 约 12/255 | `lift: 0.045`，11.5/255 |
| 最亮的白 | 约 235/255 | `gain: 236/255` |
| 饱和度 | 约 2/255：灰色 | 无色相的中性色 |
| 辉光 | 看不到 | `bloom: 0.04` |

## 调色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `page` | `#0c0c0c` | 页面及其周围的虚空 |
| `ink` | `#ececec` | 镜头要讲的那一件东西 |
| `ink2` | `#a0a0a0` | 次要文字 |
| `ink3` | `#6a6a6a` | 标签、坐标轴 |
| `ink4` | `#3c3c3c` | 一切处于关闭状态的元素 |

层次来自明度和焦点。
没有强调色可以依靠，
所以每个镜头都必须决定，哪一个元素用 `ink`。

字体是 IBM Plex Sans 和 IBM Plex Mono，
随仓库放在 `fonts/` 中，保证每台机器渲染出相同的字形。

## 调色，按顺序

1. **泛光**，几乎没有（0.04）。
2. **曝光**，然后是 Khronos PBR Neutral 色调映射，
   它在柔和压缩高光的同时，让灰色保持为灰色。
3. **色差**（0.0025），越靠近四角越强。
4. **暗角**（0.28），柔和。
5. **黑位提升和白位增益**，在显示空间中进行：
   黑色从不低于 11.5/255，白色从不高于 236/255。
   胶片拷贝永远到不了纯黑，
   抬高的黑位也让暗部的焦外虚化在页面上依然可见。
6. **颗粒**（0.02），在中间调最强，和胶片一样。
   它还能掩盖平滑焦外虚化中的色带。
7. **抖动**，幅度为一个色阶，用来防止 8 位输出中出现色带。

开头和结尾的淡入淡出都落在抬高的黑位上。

## 什么时候改

做 GIF 时，设置 `grain: 0` 和 `ca: 0`：
噪点是 GIF 唯一压缩不了的东西（[渲染管线](pipeline.md)）。
如果品牌有自己的颜色，就让页面保持灰色，
把这种颜色只用在镜头要讲的那一件东西上。
