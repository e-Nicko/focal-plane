# 镜头光学

让这种技法成立的是景深。
它让一个处在透视中的扁平界面，
看起来像一件放在桌上、用微距镜头拍摄的物体。

## 模糊在说“又小又近”

模糊的程度告诉眼睛，东西有多远、有多大。
横贯整个仪表盘的强烈模糊梯度，
会让它看起来像一个离镜头很近的小物体（Held 等，2010，见[为什么有效](why-it-works.md)）。
这正是这种技法追求的实体感。

## 薄透镜

每个像素根据自身深度得到一个弥散圆，以像素为单位：

```
c = K · (1/z_focus − 1/z) · H
```

- `z` 是像素沿视轴的距离，
  `z_focus` 是对焦距离，
  `H` 是以像素计的画面高度。
- `K` 就是相机关键帧里的 `aperture` 字段：值越大，景深越浅。
  示例影片使用 0.28 到 0.42。
- `c` 在焦平面之前为负，在焦平面之后为正，
  并被限制在画面高度的 3.8% 以内。

相机离页面越低，需要的 `aperture` 值就越小。
陡峭对角线镜头贴近页面、又偏向一侧，本身就跨越很长的深度范围，
所以 0.3 就足够了（tabs、horizon）。
近正面镜头几乎没有深度跨度，
所以要到 0.4 或更高才会出现模糊（forecast、anomaly）。

## 焦点是页面上的一个点

镜头不直接设定对焦距离。
它的 `state(t)` 返回 `focus: [x, y]`，即页面上一个以 canvas 像素表示的点，
引擎沿视轴测量到这个点的距离。
相机移动时，焦点始终停留在那个东西上。

## 移焦：先因，后果

焦点先落在控件上，再移到它所改变的东西上。
在 forecast 镜头中：

| 时间 | 发生了什么 |
|---|---|
| 0.0–0.52 秒 | 光标移向开关；焦点在开关上 |
| 0.6 秒 | 点击 |
| 0.72 秒 | 预测曲线开始生长 |
| 0.85–1.5 秒 | 焦点从开关移到预测曲线的末端 |
| 1.55–2.0 秒 | 预测值淡入，处于合焦状态 |

等效果开始之后再移焦：
视线应当落在已经有事情在发生的地方。

## 焦外虚化

聚集（gather）阶段沿黄金角螺旋采样，
参照 Dennis Gustafsson 的单遍焦外虚化方法：
draft 预设用 110 个采样，high 预设用 260 个，母版用 720 个。
靠近画面边缘时，焦外虚化会变成猫眼焦外，
与带有机械暗角的真实镜头一样。
预滤波用 Karis 权重对亮像素求平均，
这样单个亮像素就不会在帧与帧之间闪烁成一个圆斑。
