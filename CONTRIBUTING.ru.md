# Участие в проекте

[English](CONTRIBUTING.md) · **Русский** · [中文](CONTRIBUTING.zh.md)

Спасибо, что улучшаете Focal Plane.
Несколько правил сохраняют его цельным.
Агенты для разработки начинают с [AGENTS.md](AGENTS.md); общие правила лежат в [.agents/rules](.agents/rules).

## Код

- **Каждый кадр — функция времени.**
  Никаких `Math.random`, `Date` и `performance.now` в планах, данных и покадровом коде движка.
  Любую случайность стройте на генераторе с фиксированным зерном (seed).
- **Планы — обычные объекты**: `{ id, duration, size, camera, state, draw }`.
  Держите `state(t)` чистой, а `draw()` синхронной.
- **Подстраивайтесь под окружающий код**: его именование, плотность комментариев, идиомы.
- **Комментарии объясняют «почему»**, по одной фразе на строку.

## Тексты

- **Короткие страницы, по одному вопросу на каждую.**
  Если странице нужно оглавление, разбейте её.
- **[Семантические переносы строк](https://sembr.org/)**:
  новая строка после каждого предложения, а где это помогает, — и после части предложения.
  В китайском переносите строку только после полноширинной пунктуации (。，；：！？),
  чтобы браузеры не вставляли пробелы между иероглифами.
- **Сначала английский.**
  Русские и китайские страницы следуют за английскими;
  изменение в одной из них — это изменение во всех трёх.
  Используйте слова из `docs/glossary.md`.
- **Указывайте источники.**
  Утверждения из исследований ссылаются на статью;
  конвенции ремесла помечены как ремесло;
  у ссылок в `docs/sources.md` есть пометка надёжности.

## Перед merge request

- [ ] `bun run typecheck` и `bun run check:docs` проходят без ошибок.
- [ ] `bun run shoot --t=1,5,9,13 --sheet` отрабатывает, и вы посмотрели на контактный лист.
- [ ] Если вы меняли движок, kit или данные:
      стоп-кадры до и после совпадают везде, кроме того, что вы собирались изменить.
- [ ] Если вы меняли пример фильма: `bun run media` пересобрал обложку, стоп-кадры и карточку для ссылок.
- [ ] Ссылки на страницах, которые вы правили, работают.
